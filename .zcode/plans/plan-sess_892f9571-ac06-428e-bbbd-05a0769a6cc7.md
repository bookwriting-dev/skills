# Per-skill audit: storycraft-skills (59 skills)

**Goal:** walk every skill and verify it does what it claims, with no dead ends — then fix what's broken under the fork's ordinary-dev loop (change → version bump → CHANGELOG → sync-manifest → commit).

## The pass standard (applied to every skill)

1. **Router** — frontmatter description's trigger phrases and do-not-use guidance match the body, `docs/USER.md`'s catalog, and the recipes.
2. **Promise vs delivery** — the body actually delivers what the description and USER.md claim; stated outputs match bundled schemas/assets; no phantom components (no `fiction-masteragent`, no "prompt compiler").
3. **Reference integrity** — every path mentioned resolves; every bundled `references/`/`assets/`/`scripts/` file is used by its own SKILL.md or a documented cross-skill consumer; script flags documented = flags implemented; scripts run clean on sample input (executed read-only, output to /tmp).
4. **Workflow wiring** — position consistent with `templates/AGENTS.md` (order, decision tree, index); every handoff names a real skill.
5. **Convention compliance** — name = folder, quoted version, valid category, output-format per convention; self-contained worker instructions; provider-neutral phrasing; diagnostics never edit; deletion-first editing; standalone scripts.
6. **Verdict** recorded per skill: PASS / FIXED (what changed) / NEEDS-DECISION (logged with recommendation).
